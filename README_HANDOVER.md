## ゲームバランス設計

### 初期状態
- 開業資金: ¥7,500,000
- スタッフ: 3名（管理者1名、看護師2名）
- 利用者: 5名
- 月間固定費: 約¥1,400,000

### 損益分岐点
- 約17名の利用者

### キャッシュフロー
- **2ヶ月遅れ入金**（レセプト請求の仕組み）
- 開業1〜2ヶ月目は入金ゼロ
- 賞与月（6月・12月）に大きな支出

### ゲームオーバー条件
- 現金残高 -300万円以下
- 人員基準割れ（常勤換算2.5人未満）が継続

### クリアランク
- S: 累計黒字3,000万円以上 + 利用者35名以上
- A: 累計黒字2,000万円以上
- B: 5年間継続 + 累計黒字

## 重要な設計判断の経緯

### なぜ「経営特化」か
- 訪問看護の特徴は「看護師が経営する」こと
- 看護の専門性を入れると「何のゲームかわからなくなる」
- カイロソフト風の「配置・拡大・効率化」に集中

### なぜ「リアルタイム」か
- お金の動きが見えると楽しい
- スタッフが動き回ることで「経営している感」
- 眺めているだけでも楽しい

### なぜ「2ヶ月遅れ入金」か
- 訪問看護経営の最大の難所
- これを体験させることが教育的価値
- キャッシュフローの重要性を学べる
