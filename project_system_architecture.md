                                        │
                                        ▼
                              患者音声生成 (VOICEVOX): ~0.14秒

                                        │
                                        ▼

## 5. PPTX→MP4動画変換パイプライン

```
  入力: .pptx ファイル
         │
         ▼
  ┌─────────────────────────┐
  │ Step 1: python-pptx      │
  │ 1スライド = 1 PPTX分割   │
  └───────────┬─────────────┘
              │ slide_001.pptx, slide_002.pptx ...
              ▼
  ┌─────────────────────────┐
  │ Step 2: PowerPoint COM   │
  │ 各PPTX → MP4エクスポート │
  │ SaveAs(path, 39)         │
  │ スライド7秒自動進行      │
  └───────────┬─────────────┘
              │ slide_001.mp4, slide_002.mp4 ...
              ▼
  ┌─────────────────────────┐
  │ Step 3: ffmpeg            │
  │ 8秒にトリム/パッド        │
  │ → MPEG-TS変換             │
  │ → concat結合              │
  │ H.264, 1920x1080, 30fps  │
  └───────────┬─────────────┘
              │
              ▼
  出力: .mp4 ファイル
  (例: 39スライド → 5m12s, ~94MB)
```
