背景画像の2分類

本プロジェクトの背景画像は用途が全く異なる2種類に分かれます。制作時に混同しないよう明確に区別します。

MAP 俯瞰MAP

役割: 場所の位置関係を鳥瞰図で示す。シーン間の移動時に表示される。

特徴:

  • 上から見下ろした地図・見取り図スタイル
  • 場所マーカー（アイコン＋ラベル）を上に配置
  • キャラクターは表示されない
  • クリックで場所を選んで移動

COPD例: map_town.png（町並み）、map_hospital.png（病院内）、map_home.png（自宅間取り）

BG シーン背景

役割: キャラクターが登場する対話シーンの舞台。キャラ立ち絵の後ろに表示される。

特徴:

  • 正面〜やや斜めのアングル（人物の目線）
  • 手前にキャラ立ち絵が重なるため、中央部を空けたレイアウト
  • 場所の雰囲気を伝える色調・小物
  • セリフ表示エリア（画面下部）と被らない構図

COPD例: bg_hospital_room.png（病室）、bg_home_living.png（居間）、bg_pharmacy.png（薬局）

以降、各領域の背景一覧では MAP と BG を明記して区別します。

シナリオJSON仕様

各事例は1つのJSONファイルで定義します。vn_viewer.htmlで読み込むと再生できます。

全体構造

{
  "meta": {            // 事例の基本情報
    "title", "subtitle", "version", "domain",
    "difficulty", "learningObjectives", "titleInfo"
  },
  "characters": {},    // キャラID → {name, folder, defaultExpression}
  "speakerNames": {},  // speaker値 → 表示名の対応
  "backgrounds": {},   // シーン背景ID → 画像パス (bg_xxx.png)
  "bgm": {},           // BGM ID → 音声パス
  "maps": {            // 俯瞰MAPの定義
    "town": {
      "image": "maps/map_xxx.png",
      "markers": [{ "id", "label", "icon", "position" }]
    },
    "subMaps": {}     // サブMAP（建物内部など）
  },
  "sceneFlow": [],     // シーン間の移動先（MAP上で次に光る場所）
  "scenes": [{         // シーン配列（本編）
    "id", "title",
    "background": "背景ID",   // backgrounds内のキーを指定
    "bgm": "BGM ID",
    "cuts": [],         // セリフ・演出の配列
    "knowledge": {},    // 学習知識パネル
    "quiz": {}          // クイズ（任意）
  }]
}

シーン構成パターン（推奨テンプレート）

COPD見本（14シーン）を分析した構成パターンです。各事例はこのパターンを組み合わせて構成します。

基本構成（8〜15シーン）

  1. イントロ — ナレーションで患者紹介・疾患説明（カット3〜4）
  2. 出会い・初回場面 — 患者と医療者の初対面（カット5〜8）
  3. 日常場面 — 患者の生活や家族との関わり（カット5〜8）
  4. 看護実践① — 看護アセスメント・ケア実施（カット5〜8）
  5. 看護実践② — 別の看護介入。リハビリ・指導など（カット5〜8）
  6. 多職種連携 — 医師・薬剤師・PT・MSWなどとの場面（カット5〜8）
  7. 患者・家族の心理 — 不安・葛藤・希望の描写（カット5〜8）
  8. 状態変化・急変 — 病状悪化や予期しない出来事（カット5〜9）
  9. 対応・回復 — 急変への対応と経過（カット4〜7）
  10. エンディング — まとめ・学びの振り返り（カット3〜6）

MAP表示のタイミング

俯瞰MAPはシーンの切り替わり時に表示されます。場所が変わるシーン間にMAPが挟まり、次の行き先マーカーが光ります。同じ場所が続くシーン間ではMAP表示をスキップできます。

タイミング表示されるMAPCOPD見本の例
広域移動（建物間）メインMAP（町並み等）病院→自宅 : map_town.png
施設内移動（部屋間）サブMAP（建物内部）居間→寝室 : map_home.png
同じ部屋で続行MAP表示なし寝室での看護ケア連続シーン
