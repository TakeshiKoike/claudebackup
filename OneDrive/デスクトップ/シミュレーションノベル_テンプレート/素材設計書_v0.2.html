シナリオJSON仕様

各事例は1つのJSONファイルで定義します。vn_viewer.htmlで読み込むと再生できます。

全体構造

{
  "meta": {            // 事例の基本情報
    "title": "メインタイトル",
    "subtitle": "サブタイトル",
    "version": "1.0",
    "domain": "在宅看護学",    // 領域名
    "difficulty": "中級",
    "learningObjectives": ["目標1", "目標2"],
    "titleInfo": ["患者情報", "疾患名", "概要"]
  },
  "characters": {      // キャラクター定義
    "patient": { "name": "氏名", "folder": "画像フォルダ", "defaultExpression": "..." }
  },
  "speakerNames": {},  // speaker値 → 表示名の対応
  "backgrounds": {},   // 背景ID → 画像パス
  "bgm": {},           // BGM ID → 音声パス
  "maps": {},          // マップ定義（マーカー付き）
  "sceneFlow": [],     // シーン間の移動先
  "scenes": [          // シーン配列（本編）
    {
      "id": 1, "title": "シーン名",
      "background": "背景ID", "bgm": "BGM ID",
      "cuts": [ ... ],     // セリフ・演出の配列
      "knowledge": { ... }, // 学習知識パネル
      "quiz": { ... }       // クイズ（任意）
    }
  ]
}

シーン構成パターン（推奨テンプレート）

COPD見本（14シーン）を分析した結果、以下の構成パターンが浮かび上がります。各事例はこのパターンを組み合わせて構成します。

基本構成（8〜15シーン）

  1. イントロ — ナレーションで患者紹介・疾患説明（カット3〜4）
  2. 出会い・初回場面 — 患者と医療者の初対面。診断告知や入院場面など（カット5〜8）
  3. 日常場面① — 患者の生活や家族との関わり（カット5〜8）
  4. 看護実践① — 看護アセスメント・ケア実施（カット5〜8）
  5. 看護実践② — 別の看護介入。リハビリ・指導など（カット5〜8）
  6. 多職種連携 — 医師・薬剤師・PT・MSWなどとの場面（カット5〜8）
  7. 患者・家族の心理 — 不安・葛藤・希望の描写（カット5〜8）
  8. 状態変化・急変 — 病状悪化や予期しない出来事（カット5〜9）
  9. 対応・回復 — 急変への対応と経過（カット4〜7）
  10. エンディング — まとめ・学びの振り返り（カット3〜6）

クイズ配置の目安

  1. 疾患の基礎知識（イントロ直後）
  2. 看護アセスメントのポイント（看護実践①）
  3. ケアの根拠・手順（看護実践②）
  4. 薬剤や治療の知識（多職種連携）
  5. 急変の徴候・対応（状態変化）

各クイズは看護師国家試験レベルの4択。複数選択（multipleAnswer: true）も可。
