第15部：Blender MCP完全解決記録（超総合版で新設）
======================================================================

■ 問題の経緯
  - 2025年10月: Blender MCP初接続成功（MacBook Air）
  - 2025年11月〜2026年3月14日: RTX 4090 PCでは断続的に接続不能
  - Claude Codeセッション内でBlender MCPツールが認識されない問題が継続
  - ユーザーの強いフラストレーションの原因の一つ

■ 根本原因（3/15に特定）
  1. Windows環境では `uvx` コマンドの直接実行がプロセス生成に失敗
     → `cmd /c uvx blender-mcp` のラッパーが必要
  2. MCP定義が2箇所に重複:
     - `~/.claude/settings.local.json`（project scope）→ Claude Codeに認識されず
     - `~/.claude.json`（user scope）→ 正しい場所
  3. `claude mcp add` で追加された定義がsettings.local.jsonに入っていた

■ 修正手順
  1. `~/.claude/settings.local.json` からblender定義を削除
  2. `~/.claude.json` のトップレベル `mcpServers` に以下を追加:
     ```json
     "blender": {
       "type": "stdio",
       "command": "cmd",
       "args": ["/c", "uvx", "blender-mcp"],
       "env": {}
     }
     ```
  3. `claude mcp list` で `blender: cmd /c uvx blender-mcp - ✓ Connected` 確認

■ 今後の影響
  - 3Dモデリング作業（GLBエクスポート、シーン構築）がClaude Code内で直接可能に
  - haru風医療離島サイトのGLBモデル作成が即座に着手可能
